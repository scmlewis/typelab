# Home Context and About Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a below-the-fold “Why TypeLab” band to the bench, a dedicated `/about` page, footer navigation, and static social metadata without changing the test-first flow.

**Architecture:** Add one lazy-loaded React route and one content section inside the existing SPA. Content is plain markup using the existing design tokens. The Open Graph image is a committed static PNG generated by a one-off Playwright script, and the metadata lives in `index.html`.

**Tech Stack:** React 19, React Router 7, Tailwind 4, Vitest + React Testing Library, Playwright, Vite.

**Spec:** `docs/superpowers/specs/2026-10-31-home-about-design.md`

## Global Constraints

- `/` must still open on the typing test, with `data-testid="typing-surface"` above the fold on a 375×667 phone viewport.
- The primary header keeps exactly three links: Test, History, Settings. About lives in the footer and the home band.
- No new runtime dependencies, analytics, accounts, or backend calls.
- Strict CSP stays intact: no inline scripts in `index.html`; metadata and the Open Graph image are static files.
- Bundle budgets remain entry JS ≤ 160 kB, all JS ≤ 340 kB, all CSS ≤ 16 kB gzip.
- Visual language stays “lab notebook”: mono labels, numbered sections, warm paper, one accent.
- All routes share the same static Open Graph metadata; per-route crawler metadata is out of scope.
- TypeScript strict mode, ESLint with zero warnings, Prettier clean.

## Review Focus

- The footer About link must not push the header nav to four items or overflow a 375 px viewport.
- `/about` must work on a hard navigation, not only client-side navigation, because Cloudflare Pages serves the SPA shell for deep links.
- `og:image` must be an absolute HTTPS URL and the image must be exactly 1200×630 PNG; relative paths and wrong dimensions break social previews.
- Copy must not overclaim: “no tracking” and “local-only” must match what the app actually does.
- The new home band must sit below the typing surface and must not break the existing above-the-fold test.
